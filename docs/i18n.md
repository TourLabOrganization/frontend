# 다국어

| 하는 일                    | 위치                                            |
| -------------------------- | ----------------------------------------------- |
| 지원 언어 목록 · 기본 언어 | `src/i18n/locales.ts` (지금은 ko · en, 기본 ko) |
| 요청마다 언어 고르기       | `src/i18n/request.ts`                           |
| 문구                       | `messages/<언어>.json`                          |
| 키 타입 검사               | `src/i18n/global.ts`                            |

- 언어는 URL이 아니라 `locale` 쿠키로 정한다. 쿠키가 없거나 목록에 없는 값이면 기본 언어를 쓴다
- 문구는 화면 단위로 묶는다: `{ "Home": { "title": "..." } }`
- 꺼내 쓰는 법
  - 서버 컴포넌트: `useTranslations("Home")`, async 함수 안에서는 `await getTranslations("Home")`
  - 클라이언트 컴포넌트: `useTranslations("Home")`
- 키는 `ko.json`을 기준으로 타입 검사된다. 새 키는 `ko.json`에 넣고 `en.json`에도 같은 키를 넣는다
- 언어를 추가하려면 `locales`에 코드를 넣고 `messages/<코드>.json`을 만든다
- 목표 언어는 PoC와 같은 5개(ko · en · zh · ja · es)다. 문구 번역이 준비되는 대로 하나씩 추가한다
- 장소 이름처럼 데이터에 딸린 번역은 문구 파일에 넣지 않는다. 한국관광공사 다국어 API 같은 데이터 쪽에서 받는다
