# 화면과 디자인

디자인 방향은 **클린 트래블**이다. 흰 바탕, 큰 굵은 글씨, 파란 포인트 하나, 넉넉한 여백, 둥근 사진 카드.
토큰은 `src/app/globals.css`, 공통 부품은 `src/components/ui/`에 있다.

## 색

기본 팔레트를 지웠다. 아래 토큰만 클래스로 쓸 수 있다(`bg-fill`, `text-fg-muted` …).
새 색이 필요하면 `globals.css`와 이 표에 함께 추가한다.

**화면 모드**: 머리줄 「화면 모드」 메뉴(`components/ui/DisplayModeSwitch.tsx`)로 기본 · 블랙 · 포레스트 · 선셋 코랄을 고른다(포레스트 · 선셋 코랄은 후보 5안 중 대표가 고른 것, 2026-09-29). 고른 값은 쿠키 `display_mode`에 두고
루트 레이아웃이 `<html data-mode>`를 처음부터 그린다(깜빡임 없음, `lib/display-mode.ts`). 블랙 모드는 `globals.css`의 `:root[data-mode="dark"]`가
면 · 글자 · 약한 브랜드 색 토큰 값만 바꾼다(토큰 이름은 그대로라 컴포넌트는 고치지 않는다). `primary`(버튼 바탕)는 흰 글씨 대비를 지키려고 그대로 둔다.
포레스트 · 선셋 코랄은 밝은 모드라 `primary`까지 그 모드 색으로 바꾸고, 테두리(`line`) · 글자는 후보보다 한 단계 진하게 했다(값과 대비는 `globals.css` 주석).
카카오 바탕 지도 · 사진 · 분류 색은 바뀌지 않는다. 모드를 더할 때는 `DISPLAY_MODES` · `THEME_COLOR` · 메뉴 아이콘 · 문구(`Header.displayMode.modes`)에 더하고 같은 방식으로 토큰을 덮는다

장소 분류 색(`cat-*`)은 투어 플래너 지도 핀(색 점)과 분류 아이콘(목록 · 분류 칩 · 담은 장소, `features/planner/CategoryIcon.tsx`)에만 쓴다. 분류는 색만으로 나누지 않고
언제나 분류 이름(`Course.categories`)을 함께 보인다. 여섯 색 모두 흰 바탕 대비 4.5:1 이상이다.

## 글자

글꼴은 Pretendard 하나다(`font-sans`). 중 · 일 글자는 뒤에 붙인 시스템 CJK 글꼴로 그린다(`docs/i18n.md`). 크기는 토큰 이름을 클래스로 쓴다.

| 클래스          | 크기 / 줄높이 | 쓰임                |
| --------------- | ------------- | ------------------- |
| `text-display`  | 28 / 1.3      | 결과 화면의 큰 제목 |
| `text-title`    | 26 / 1.35     | 화면 제목(문항)     |
| `text-headline` | 19 / 1.4      | 섹션 제목           |
| `text-body-lg`  | 17 / 1.5      | 보기, 버튼          |
| `text-body`     | 16 / 1.6      | 본문                |
| `text-label`    | 15 / 1.5      | 보조 설명           |
| `text-caption`  | 13 / 1.45     | 배지, 메타 정보     |
| `text-micro`    | 12 / 1.4      | 출처 표기           |

- 제목은 `font-bold`, 보기·버튼은 `font-medium`·`font-semibold`, 본문은 기본 굵기
- 모바일 본문은 16px(`text-body`) 이상. 13px 이하는 배지·출처처럼 짧은 글에만 쓴다

## 모양과 간격

- 둥근 모서리: 버튼·보기 `rounded-2xl`(16px), 큰 카드 `rounded-card`(20px), 배지 `rounded-lg`(8px)
- 그림자는 쓰지 않는다. 층위는 면 색(`surface`·`fill`)과 여백으로 나눈다
- 화면 좌우 여백은 목록 20px(`px-5`), 글 덩어리 24px(`px-6`). 간격은 4의 배수로 둔다

## 레이아웃

- 모든 화면은 `<Screen>`으로 감싼다. 모바일은 전체 폭, 넓은 화면에서는 가운데 480px 기둥이다
- 위는 `<TopBar>`, 화면의 주요 버튼은 `<BottomBar>`에 넣는다. 한 화면에 주요 버튼은 하나
- 홈 · ME처럼 주요 버튼 없이 여러 화면으로 갈라지는 화면은 `<BottomBar>` 대신 `<BottomNav>`(하단 탭)를 둔다
- 테마 화면 · 투어 플래너처럼 한 화면 안에서 `?tab=`으로 나뉘는 화면은 `BottomNav`와 같은 모양의 `TabBar`를 둔다
  (테마: `features/theme/ThemeTabBar` 지도 · 코스 · 영화 · 스탬프 · 여행 정보, 플래너: 지도 · 코스 · 여행 정보)
- 모바일(390px)부터 만든다. 지도·플래너처럼 넓은 화면에서 이점이 큰 화면만 `md:` 이상에서 두 단으로 편다

홈 · ME 머리줄 오른쪽(언어 메뉴 · 검색 · 알림)은 `components/HeaderActions`, 알림은 `components/Notifications`(내용은 `lib/notifications.ts`)다.
플래너 · 테마 코스 탭 「내 플랜」의 저장소 목록(접이식, 행마다 불러오기 · 삭제)은 `components/PlanStore`다.

플래너 코스 탭 일자별 일정의 날마다 날씨 줄(2026-10-03, `features/planner/course-weather.ts`): 여행 날짜 중 예보가 닿는 날(오늘 ~ 오늘 + 15일)은 「날씨 {종류} · 최고 n° · 비 n mm」를 보이고, 비(강수 5mm 이상 또는 비 · 소나기 · 뇌우 · 눈) · 폭염(최고 33° 이상) 예보일은 경고 줄과 그날 야외 장소(식당 · 숙박 제외, 이름에 박물관 · 미술관 · 전시 · 시장 · 온천 · 카페 같은 실내 말이 없는 곳)를 적고, 장소마다 같은 도시의 실내 장소 3곳(가까운 순, 코스 밖)을 「+ 이름」 칩으로 보여 누르면 그날에 담긴다(`dayAdd.added` 안내). 예보는 코스 첫 장소 좌표로 한 번 받는다(`/api/weather?from=&to=`). 날짜를 고르지 않았으면 오늘 하루만. 첫 날씨 줄에 Open-Meteo 출처를 적는다

새 부품이 필요하면 이 표에서 먼저 찾고, 없으면 같은 폴더에 만들어 표에 추가한다.

## 아이콘과 이미지

- 서비스 로고는 `LogoMark`로만 그린다(lucide 아이콘으로 대신하지 않는다).
- 아이콘은 lucide-react만 쓴다. 크기는 20·24, 기본 굵기. 글자 옆에 붙는 작은 표시(칩 안 · 새 창 · 고름 체크 · 펼침 화살표 · 오류 문구 앞)만 16. 이모지를 아이콘 대신 쓰지 않는다. 장식용 아이콘에는 `aria-hidden`
- 이미지는 `next/image`로 넣는다. 외부 도메인 이미지는 `next.config.ts`의 `images.remotePatterns`에 도메인을 추가한다
- 장소 사진(Wikimedia Commons)은 `unoptimized`로 브라우저가 Wikimedia에서 바로 받는다. Wikimedia가 이미지 최적화 서버의 요청에 429를 돌려준다.
  사진 아래에 출처(「사진: Wikimedia Commons」)를 적는다
- 영상 작품의 포스터 · 스틸은 TMDB 이미지(`src/features/recommend/works.ts`)를 쓰고, 그 화면에 TMDB 출처(`Common.tmdbCredit`)를 표기한다.
  포스터 저작권은 배급사 · 제작사에 있다. 2025 공모요강은 타인 저작권에 저촉되면 심사 제외 · 수상 취소라서, 공모전 제출물에 쓰기 전에 팀에서 확인한다
- 그 밖의 사진은 한국관광공사 사진 서비스처럼 이용 허락이 분명한 것만 쓴다

## 상호작용과 접근성

- 누를 수 있는 것은 44px 이상, 서로 8px 이상 띄운다
- 누르면 바로 반응한다(`active:scale-[0.98]` 또는 배경색). 전환은 150~300ms
- 키보드 포커스 링을 지우지 않는다(`focus-visible:outline-primary-bright`)
- 움직임 줄이기 설정이면 애니메이션을 끈다(`motion-reduce:`)
- 한글은 단어 단위로 줄바꿈한다. `body`에 `break-keep`이 걸려 있으니 풀지 않는다.
  URL처럼 띄어쓰기 없이 긴 문자열이 들어가는 곳에만 `break-all`을 따로 준다
